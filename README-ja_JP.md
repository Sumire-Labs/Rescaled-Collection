# Rescaled Collection

既存のScala 2 Modを Cleanroom / Java 25 + Scala 3 環境向けに移植し保守する非公式フォークコレクションです。
これは、各プロジェクトのソースを含んだモノレポではなく、Sumire Labsが保守しているRescaled Modのリンク集のようなものです。

問題や議論がある場合は、各プロジェクトのissuesまでお願いします。
CF/MRへのアップロードはそのうち行いますので。しばらくの間お待ちください
