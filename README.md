# Rescaled Collection

An unofficial collection of forks that ports and maintains existing Scala 2 mods for Cleanroom / Java 25 + Scala 3.
This is not a monorepo containing each project's source code, but rather a collection of links to Rescaled mods maintained by Sumire Labs.

For issues or discussions, please visit each project's issue tracker.
Uploads to CF/MR will come later. Please bear with us in the meantime.
