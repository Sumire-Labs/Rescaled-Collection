# Rescaled Collection

기존 Scala 2 Mod를 Cleanroom / Java 25 + Scala 3 환경으로 포팅하고 유지보수하는 비공식 포크 모음입니다.
각 프로젝트의 소스 코드가 포함된 모노레포가 아니라, Sumire Labs가 유지보수하는 Rescaled Mod의 링크 모음과 같은 것입니다.

문제나 논의할 사항이 있으면 각 프로젝트의 Issues를 이용해 주세요.
CF/MR 업로드는 추후 진행할 예정이니, 조금만 기다려 주세요.
