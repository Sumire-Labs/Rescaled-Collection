# Rescaled Collection

这是一个非官方分支合集，用于将现有的 Scala 2 Mod 移植到 Cleanroom / Java 25 + Scala 3 环境并进行维护。
这并不是包含各个项目源代码的单一仓库，而更像是由 Sumire Labs 维护的 Rescaled Mod 链接合集。

如有问题或需要讨论，请前往各个项目的 Issues。
之后会上传至 CF/MR，请再耐心等待一段时间。
